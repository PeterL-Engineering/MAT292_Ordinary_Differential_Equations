\subsubsection{Local Truncation Error for Runge-Kutta Method on H-H Equations}

The fourth-order Runge-Kutta (RK4) method uses four slope evaluations:

\begin{align}
k_1 &= h \cdot f(t_n, V_n, m_n, h_n, n_n) \\
k_2 &= h \cdot f(t_n + \frac{h}{2}, V_n + \frac{k_1}{2}, m_n + \frac{k_1^m}{2}, h_n + \frac{k_1^h}{2}, n_n + \frac{k_1^n}{2}) \\
k_3 &= h \cdot f(t_n + \frac{h}{2}, V_n + \frac{k_2}{2}, m_n + \frac{k_2^m}{2}, h_n + \frac{k_2^h}{2}, n_n + \frac{k_2^n}{2}) \\
k_4 &= h \cdot f(t_n + h, V_n + k_3, m_n + k_3^m, h_n + k_3^h, n_n + k_3^n) \\
V_{n+1} &= V_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{align}

The exact solution expands to:
\begin{equation}
V(t_{n+1}) = V(t_n) + h V'(t_n) + \frac{h^2}{2} V''(t_n) + \frac{h^3}{6} V'''(t_n) + \frac{h^4}{24} V^{(4)}(t_n) + \frac{h^5}{120} V^{(5)}(\xi)
\end{equation}

RK4 matches the Taylor series up to the $h^4$ term, giving LTE:
\begin{equation}
\tau_n^V = \frac{h^5}{120} V^{(5)}(\xi) = \mathcal{O}(h^5)
\end{equation}

Similarly for gating variables:
\begin{equation}
\tau_n^m = \mathcal{O}(h^5), \quad \tau_n^h = \mathcal{O}(h^5), \quad \tau_n^n = \mathcal{O}(h^5)
\end{equation}

\textbf{Advantages for H-H Equations:}
\begin{itemize}
    \item Highest accuracy among common methods ($\mathcal{O}(h^5)$ LTE)
    \item Excellent handling of nonlinear terms and coupling
    \item Superior stability for stiff systems
    \item Global error of $\mathcal{O}(h^4)$ allows larger step sizes
\end{itemize}

\textbf{Computational Cost:}
\begin{itemize}
    \item Requires four function evaluations per time step
    \item Most expensive per step but can use larger $h$ for same accuracy
    \item Preferred for high-accuracy H-H simulations
\end{itemize}
