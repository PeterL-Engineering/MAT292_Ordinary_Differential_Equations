\subsubsection{Euler's Method}
\label{subsubsec:euler-method}

Euler's method is a straightforward numerical technique for solving differential equations by constructing approximations using tangent lines. Given:

\[
\frac{dy}{dt} = f(t, y), \quad y(t_0) = y_0,
\]

we start at \((t_0, y_0)\) and use the slope to form the tangent line:

\[
y = y_0 + f(t_0, y_0)(t - t_0)
\]

Evaluating at \(t = t_1\) gives the next point. The iterative formula is:

\[
y_{n+1} = y_n + f(t_n, y_n) \cdot \Delta t,
\]

where \(\Delta t = t_{n+1} - t_n\) is the step size. As \(\Delta t \to 0\), this piecewise linear approximation converges to the true solution \(\phi(t)\).

\subsubsection{Improved Euler's Method}
\label{subsubsec:improved-euler}

The improved Euler's method (Heun's method) is a predictor-corrector approach that achieves better accuracy by averaging slopes. Given the same initial value problem, the method proceeds in two steps:

\[
\begin{aligned}
y_{n+1}^* &= y_n + f(t_n, y_n) \Delta t &\text{(predictor)}\\[1pt]
y_{n+1}   &= y_n + \frac{f(t_n, y_n) + f(t_{n+1}, y_{n+1}^*)}{2} \Delta t &\text{(corrector)}
\end{aligned}
\]

The predictor uses standard Euler, then the corrector averages the slopes at the beginning and end of the interval for better accuracy.

\subsubsection{Runge-Kutta Method}
\label{subsubsec:runge-kutta}

The fourth-order Runge-Kutta method provides excellent accuracy with reasonable computational cost. It requires four slope evaluations per step:

\[
\begin{array}{ll}
k_1 = f(t_n, y_n) & k_3 = f\bigl(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}k_2\bigr) \\[1pt]
k_2 = f\bigl(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}k_1\bigr) & k_4 = f\bigl(t_n + h,\; y_n + h k_3\bigr)
\end{array}
\]

where \(h = \Delta t\). These are combined:

\[
y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4).
\]

Despite more function evaluations per step, its higher accuracy often allows larger step sizes, making it a popular choice for solving ODEs.
